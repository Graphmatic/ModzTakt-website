# ModzTakt promo site scaffold

Angular starter structure for the Graphmatic/ModzTakt website.

What is included:
- sticky top menu with Home / ModzTakt / placeholder / Download / Changelog
- blog-style home page
- ModzTakt page built from README content
- Download page that reads GitHub Releases at runtime
- palette styling matching the requested light grey / black / dark grey / light blue look
- image assets cropped from the repository screenshot for section details

Run:
```bash
npm install
npm start
```
